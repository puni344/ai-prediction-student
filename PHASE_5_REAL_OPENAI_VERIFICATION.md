## 4. Real Recommendation Test

To verify the real OpenAI client execution path, `OpenAIClient` was directly invoked with the provided API key and authenticated student context:

```
Student Context + Deterministic Candidates
                │
                ▼
      OpenAIClient.generate_recommendations()
                │
                ▼
      OpenAI Beta Chat Parse API (https://api.openai.com/v1)
```

### Runtime Result:
- The OpenAI API server rejected the request with HTTP 401 Unauthorized:
  ```
  AuthenticationError: Error code: 401 - {
    'error': {
      'message': 'Incorrect API key provided: AQ.Ab... You can find your API key at https://platform.openai.com/account/api-keys.',
      'type': 'invalid_request_error',
      'code': 'invalid_api_key'
    }
  }
  ```
- **Root Cause**: The key provided is a Google Gemini key (`AQ.Ab...`). OpenAI's API strictly requires a valid OpenAI key (`sk-...`).
- **Resilient Fallback**: The backend caught the `AuthenticationError`, activated the deterministic fallback, set `ai_enhanced: false`, and assigned `ai_status: "deterministic_fallback"`.
